# @tasteee/maddie

A framework-agnostic, browser-based MIDI editor. Ships as web components on top of a headless core.

- Use the full editor: `<maddie-editor>`
- Or compose your own from the pieces: `<maddie-piano-roll>`, `<maddie-keyboard>`, `<maddie-velocity-lane>`, …
- Or go headless with `@tasteee/maddie/core`

Status: design phase. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
