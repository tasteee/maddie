Foundations

The editor is built on Zest and follows it wherever it can: Zest's light theme, its roles, its radii, its floating shadow. It only steps away where the editor needs something Zest doesn't have (M/S toggles, track tabs, the piano roll). Every color here is a Zest token, read straight from Zest's tokens.css.

What color means

Each color has one job.

  • Zest's primary tone is neutral (near-black on light). Use it for normal buttons and the volume slider fill.
  • tone="secondary" (violet) means "on" or "the main action." Play is the only solid secondary button. Toggles that are on use the secondary tone.
  • tone="danger" is only for Record, the capture-ready dot and the capture toast.
  • status-warning is only for an active M toggle.
  • z-status-dot status="online" is only for "MIDI controller connected."
  • Spark colors belong to tracks only: the dot, tab tint and notes.

Depth

Zest's rule, unchanged.

  • Resting UI is flat: a surface plus a 1px border. Bars, chips, tabs, buttons and the transport capsule never get a shadow.
  • Floating UI gets --shadow-overlay: popovers, menus, select panels, tooltips, the toast and the zoom pad. Zest's components already do this.
  • Pressed and selected change the surface, never the elevation.
  • Focus is a ring (border-focus), never a shadow.

Dense region

Zest's controls are sized for forms (sm = 32px). The editor shrinks them in one place by scoping the tokens. The controls themselves are never resized by hand.

<div class="editor-shell" data-theme="light" data-zest-scope> .editor-shell { --base-font-size: 14px; --control-height-xs: 1.5rem; --control-height-sm: 1.75rem; --control-height-md: 1.875rem; }
  • data-zest-scope makes Zest recompute font, spacing and radius from the scoped base values for this region only.
  • --control-height-xs is a Zest addition (see the agent instructions).

Popover rules

All panels are z-popover. All action menus are z-menu.

  • Zest already handles closing on outside click and Esc, moving focus in and back to the trigger, staying anchored and flipping near edges.
  • One open at a time comes for free: clicking another trigger counts as an outside click.
  • Placement: bottom-start for triggers in the left half, bottom-end in the right half. offset 6.
  • Widths via --z-overlay-max-width: menus 232, panels 272, wide panels 304, project menu 288.
  • Picking a radio-style menu option closes the menu. Changing a setting inside a panel doesn't.
  • Reopening resets it: searches clear, drill-in views go back to the first view (app state).

Keyboard and focus

suggested marks ideas, not existing features.

  • Focus ring comes from Zest (border-focus). Custom pieces (track tabs, M/S, zoom pad) must copy it.
  • Icon-only buttons get an aria-label. Zest passes it to the inner button. z-tooltip shows the same words.
  • Esc closes the open popover (Zest).
  • Space play / pause suggested
  • − = shift the computer keyboard's base octave.
  • Alt while dragging notes bypasses snap suggested
