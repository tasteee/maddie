Input — behavior

Two independent sources. Either, both or neither can be on. A wide panel (304px), right-aligned to the chip.

Chip
  • Dot: green when the MIDI controller is on, border-strong grey when it's off. If the chosen device disconnects, the dot goes grey too. to decide
  • Keyboard icon (accent) shows only while the computer keyboard is on. It's a reminder that typing plays notes.
Computer keyboard
  • The switch shows or hides its settings in a surface sub-panel right under it. It isn't on its own row.
  • Play in key: when on, every computer key plays a note in the project key. Hint: "Only play notes in C minor." With no key set, the switch is disabled and the hint says "Pick a key first."
  • Base octave: the octave the lowest computer keys play in. A stepper from 0 to 7, showing just the number. Each button disables at its limit. − = change it from anywhere, and the stepper updates to match.
MIDI controller
  • The switch shows or hides a device select right under it, at full width.
  • Device list: "All devices" first, then each connected input by its system name. The list updates while it's open when devices connect or disconnect.
  • If the chosen device disappears, the select shows its name with "(disconnected)" and keeps it, so it reconnects by itself. to decide
Panel
  • Order: title · Computer keyboard · its settings · divider · MIDI controller · its device select.
  • Changing settings never closes the panel.
  • The panel grows and shrinks downward only; the chip never moves.

Output — behavior

Where sound goes and how loud. A wide panel (304px), right-aligned to the chip.

Sound
  • One select, two kinds of choice. "MIDI output" is always the first option. Then every built-in instrument, grouped by category (Keys, Bass, Leads, Pads, Mallets & plucks). An instrument and MIDI output can't both be on.
  • Picking MIDI output shows a "MIDI port" select right under it, listing system output ports. Picking an instrument hides it again.
  • The instrument applies to the whole project. If it becomes per track later, this moves onto the track. to decide
Volume rows
  • Layout: a label on the left with the value on the right (plain value-label text, not a colored badge). Under that, a 22px icon button and then the slider.
  • Volume: the speaker button mutes and unmutes. While muted, the value reads "Muted," the slider dims, and the chip's icon switches. Dragging the slider unmutes.
  • Metronome volume: the metronome button is the same toggle as the one in the transport, and they stay in sync. While off, the value reads "Off" and the slider dims. Dragging the slider turns the metronome on.
  • Sliders go 0–100 in steps of 1. ← → nudge by 1, and Shift nudges by 10.
