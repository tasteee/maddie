Track tabs — behavior

Picking, muting, soloing, removing.

  • Clicking the name makes it the active track. New notes go there, and its notes are drawn solid. Other tracks show as outlined ghost notes at 45% opacity.
  • M and S toggle on their own and never change which track is active.
  • Solo: if any track is soloed, every track that isn't soloed goes silent and fades back. Several tracks can be soloed at once. A muted track stays silent even when soloed.
  • Remove (×): removes the track and can be undone, with no confirm dialog. Hidden when only one track is left. If you remove the active track, the first remaining track becomes active.
  • Double-click the name to rename it in place. suggested
  • Too many tracks: the strip scrolls sideways with a 24px fade at the cut-off edge. Past about 8 tracks, move to a track list down the left side. to decide

Grid — behavior

What each setting changes.

  • Division sets the note length for drawing and snapping, and the spacing of the faint grid lines.
  • Feel multiplies that length: triplet × 2/3, dotted × 1.5. The chip adds T or "." in accent after the fraction.
  • Beat and bar lines always show, whatever the division. Lines from faint to strong: subdivision, beat, bar.
  • The magnet and the panel switch are the same setting, so they always match.
  • Snap off: notes move freely. Grid lines stay visible.

What "key" means

One word everywhere, so nobody gets lost.

Key = Root + Scale C + Minor → C minor
  • Every control, hint and toast says key: Highlight key, Lock to key, Play in key, Fold → In key, "Pick a key first."
  • Scale only appears as the field name inside the Key panel, next to Root.
  • Never use "keys" to mean computer keys in the same sentence as a musical key. Say "computer keys" or "keyboard keys."

Key — behavior

How picking, searching and clearing work.

  • Root: 12 options in a 6 × 2 grid, built as one z-toggle-button-group with columns="6" (a Zest addition), sharps and flats spelled the usual way (C♯, E♭, F♯, A♭, B♭). Clicking one with no key set uses the last scale (Minor by default).
  • Scale list: 2 columns, scrolling in a 168px box. The count on the right ("38 scales") shows how many exist.
  • Search filters by name as you type and clears when the panel reopens. With no matches it shows "No scales match."
  • Picking a scale with no key set sets the root to C.
  • Clear only shows when a key is set. It removes the key, and turns Fold → In key back off if that was on.
  • Detect from notes sets the most likely root and scale from the notes in all tracks. If nothing fits, toast: "Couldn't detect a key." to decide
  • Highlight key changes the row shading (spec 5). Lock to key adds the lock icon to the chip.
  • Without a key, Highlight and Lock keep their switch positions but do nothing.

Fold — behavior

Hides rows; never changes notes.

  • Notes shows only pitches that have a note in any track, not just the active one.
  • In key shows only pitches in the project key. Out-of-key notes are hidden while folded, never moved.
  • While folded, every row on the keyboard column gets its note name (C4, E♭4…), not just the Cs.
  • Clearing the key while In key is on turns fold off.
  • New notes drawn while folded can only go on rows you can see.
